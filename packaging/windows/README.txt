foodnet for Windows
===================

foodnet builds taxon and metabolite networks from the batch monocultures in mGrowthDB. This folder is the
whole program: nothing else needs installing, not even Python.

Start it
--------
1. Unzip the download (right-click, Extract All). Running it from inside the zip does not work.
2. Open the extracted folder and double-click foodnet.exe.
3. A black window opens and shows an address; your browser opens the foodnet page there. Keep the black
   window open while you work: it is the program.

Stop it: close the black window (or press Ctrl+C in it).

What Windows will say, and why
------------------------------
Windows warns about any new program it has not seen many people run. foodnet is new and made by a small
research collaboration, so you will see this the first time:

  "Windows protected your PC"  ->  click the small "More info" link under the message; only then
                                   does a "Run anyway" button appear. Click it.

This is Windows being cautious about an unfamiliar program, not a finding about foodnet. The program is
built in public from the source code at https://github.com/hallucigenia-sparsa/foodnet by its automated build,
and it runs only on your computer.

On Windows 11 with Smart App Control switched on, Windows may block the program instead of warning, with
no "Run anyway". In that case, install foodnet with Python instead (see "Other ways to install" on the
project page); it gives the same program.

Some antivirus programs are suspicious of programs packed this way. If yours stops foodnet, you can
report it as a false positive to your antivirus vendor, or use the Python install.
